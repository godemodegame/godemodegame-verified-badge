# Privacy Policy

Godemodegame Verified Badge does not collect, store, sell, share, or transmit user data.

The extension runs a content script on x.com and twitter.com so it can detect @godemodegame profile surfaces and add a local visual badge in the current browser page. This processing happens locally in the user's browser.

The extension does not use analytics, does not contact developer-controlled servers, does not use cookies, and does not access Chrome storage.

The extension changes only the local browser view. It does not verify the X account on X servers and does not change what other X users see.
