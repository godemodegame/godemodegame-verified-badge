# Chrome Web Store Listing Draft

## Product Details

Name:
Godemodegame Verified Badge

Short description:
Shows a local verified badge for @godemodegame on X.

Detailed description:
Godemodegame Verified Badge adds a local visual verified badge for @godemodegame on X/Twitter in your own browser view.

The extension runs only on x.com and twitter.com. It injects a badge near the @godemodegame profile name and related account surfaces, and shows the verified account panel when you hover or click the badge.

The extension does not create official verification on X servers, does not change what other users see, and does not collect, store, or transmit user data.

Suggested category:
Social & Communication

Language:
English

## Privacy Practices

Single purpose:
Adds a local visual verified badge for @godemodegame on x.com and twitter.com.

Permission / host access justification:
Access to x.com and twitter.com is required so the content script can detect @godemodegame profile surfaces and insert the local badge in the page.

Data usage:
The extension does not collect, store, sell, share, or transmit user data. All page inspection and badge insertion happens locally in the browser.

## Test Instructions

1. Install the extension.
2. Open https://x.com/godemodegame or https://twitter.com/godemodegame.
3. Confirm the badge appears next to the profile display name.
4. Hover or click the badge and confirm the verified account panel opens.
5. Open /godemodegame/about and confirm the injected verified row appears.

No login credentials are required to test the extension.
